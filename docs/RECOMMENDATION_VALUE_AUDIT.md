# 추천 요약 값 검증 문서

## 1) 값의 성격 구분(원천 / 파생 / 시뮬레이션)

| 항목 | 구분 | 설명 | 사용 데이터셋 |
|---|---|---|---|
| 전세보증금(`deposit_price_krw`) | 파생 | 원천 거래 데이터의 자치구 단위 중앙값 | `seoul_apt_rent_5y.csv` |
| 월세(`monthly_rent_active_krw`) | 파생 | 월세>0 거래만 집계한 자치구 단위 중앙값 | `seoul_apt_rent_5y.csv` |
| 대표 매매가(`sale_price_krw`) | 파생 | 자치구 단위 매매가 중앙값 | `apt_deal_total.csv` |
| 통근시간(`commute_minutes` 등) | 시뮬레이션 | 자치구 중심점~직장 허브 거리 + 회귀계수 기반 추정 | `commute_models.csv` + `GU_CENTERS` |
| 2/3년 매수 가능성 | 시뮬레이션 | 매수가와 추정 매수여력의 차이를 상태로 분류 | `persona_profiles.csv`, `compact_housing.csv` |
| 평수/면적 구간 | 파생 | 사용자 선택 구간(예: 20~29평)으로 필터링된 집계 범위 | `compact_housing.csv` |

검증 결론: 추천 요약의 전세/월세/매매가는 **국토교통부 실거래가 기반 집계값(파생)**이며, 통근·매수 가능성은 **모형 기반 시뮬레이션**이다.  
또한 `distribution_license`는 원천에서 제거되어 현재 추천/점수 계산에 사용하지 않는다.

## 2) 계산 로직(핵심)

- 전세보증금: `median(보증금_만원_krw)` by `gu, year, area_bucket`
- 월세: `median(월세_만원_krw where 월세>0)` by `gu, year, area_bucket`
- 통근시간(맞벌이): `0.55 * 직장1 + 0.45 * 직장2`, 최장통근은 `max(직장1, 직장2)`
- 매수 갭: `buy_2y_gap_krw = sale_price_krw - buying_power_2y_krw`, `buy_3y_gap_krw` 동일

## 3) 전세보증금·월세 분포(배포 데이터 기준)

기준: `compact_housing.csv`, `year=2025`, `20~29평(대표값 24평)`, 자치구 25개.

## 4) 허위 데이터(가상 생성) 점검

- 개인 단위 레코드(개별 부부/개별 거래) 임의 생성 없음.
- 사용 값은 모두 원천 집계 또는 명시된 수식 기반 파생/시뮬레이션.
- 시뮬레이션 항목은 표기상 별도로 구분하며, 원천값으로 오인되지 않도록 대시보드 탭에서 문서와 함께 공개.
