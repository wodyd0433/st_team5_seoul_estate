# deploy

`deploy/`는 Streamlit 앱이 경량 모드에서 직접 읽는 배포용 CSV를 둔다. 원천 `raw/` 전체를 함께 배포하지 않아도 대시보드가 동작하도록 구 단위 요약본으로 축약한 데이터다.

## Files

- `compact_housing.csv`
  전월세와 매매 데이터를 `구 + 연도 + 평형 버킷` 기준으로 집계한 표다.
  전세보증금 중앙값, 월세 중앙값, 매매가 중앙값, 거래건수 등이 들어간다.
- `compact_district_metrics.csv`
  인프라, 치안, 정비사업 관련 구 단위 집계표다.
  병원 수, 공원 수, 대형마트 수, 범죄 총량, 경찰 만족도, 정비사업 건수 등이 들어간다.
- `commute_models.csv`
  광화문역, 강남역, 성수역, 여의도역 통근권 데이터로 적합한 회귀계수 표다.
  거리와 환승 수를 이용해 예상 통근시간을 계산할 때 쓴다.
- `persona_profiles.csv`
  신혼부부 소득/부채 원천을 기반으로 만든 페르소나 요약표다.
  예산 상한, 월세 상한, 점수 가중치가 들어간다.
- `.gitkeep`
  폴더 유지를 위한 placeholder다.

## Transform Rules

- 생성 스크립트
  `tools/scripts/build_deploy_data.py`
- 주택 데이터
  원천 전월세/매매 거래를 읽은 뒤 평형을 평 단위 버킷으로 내리고, 구·연도·버킷별 중앙값과 거래건수로 압축한다.
- 구 단위 지표
  인프라, 치안, 정비사업 데이터를 모두 구 단위로 집계해 하나의 테이블로 합친다.
- 페르소나/통근
  소득·부채 기반 페르소나와 통근 회귀모델은 앱 로딩 시간을 줄이기 위해 사전 계산 후 CSV로 저장한다.
